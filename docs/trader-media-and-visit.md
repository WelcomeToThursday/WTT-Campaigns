# Trader visits

With a campaign character active, choose **Visit** beside Buy and Sell at Prapor, Therapist, Fence, Jaeger, Mechanic, Ragman, Skier or Peacekeeper.

Visits open an animated trader room. They are available even when the campaign has no authored story; conversations appear only when the campaign supplies eligible dialogue.

## Conversation controls

- Use **Continue** to advance automatic dialogue and acknowledge closing text.
- Select a reply to continue the conversation. Some replies require confirmation or item selection.
- Scroll dialogue/history and replies separately when there is more text than fits.
- Use **Leave** to exit the visit, or the Buy/Sell navigation to return to trading.
- Use **Skip** when offered by media playback.

Item handovers use the game's item selection window. Cancelling an uncommitted handover cancels the pending conversation operation. See [story and quests](story-system.md) for supported actions and limits.

## Rooms and loading

A loading screen remains visible while the trader room loads. Leaving during loading cancels the visit.

The eight built-in trader bundles occupy approximately **1.69 GB**. Room textures use reduced resolutions, so small prop details and posters can look softer than the original assets.

Peacekeeper uses a custom logistics office and an approximate character model. Recovered Peacekeeper voice recordings and facial animation are not included.

If a room cannot load, check the client log for a missing media file or checksum mismatch and reinstall the matching release files. A custom campaign can supply its own room; obtain that campaign's separate media package as well.
