# Campaign introduction

Use the information button at the top right of a campaign character card to open the five-page introduction. It is available before and after character creation and always starts on the welcome page.

The pages explain the bundled campaign, campaigns in SPT, campaign characters, modifiers and the Battle Pass.

- Use the previous/next buttons, Q/E, Left/Right Arrow or mouse wheel to change pages. Navigation wraps at either end.
- Choose **CLOSE**, or press Escape or F8, to return to the same character selector.
- Reopen the information button whenever you want to read it again.

Reading the introduction does not create or select a character. The [Battle Pass tutorial](battle-pass-ui.md#tutorial) is a separate guide inside the campaign hub.
