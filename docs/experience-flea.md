# Seasoned PMCs and No Flea Market

## Seasoned PMCs

This common campaign rule multiplies newly earned PMC experience by **1.25**. It covers raid experience, examination, quest and achievement awards, and treatment awards. Existing XP is not increased retroactively, and Scav XP is unaffected.

Raid survival, death and run-through multipliers still apply. Already calculated raid XP is not multiplied again when the server saves it.

For an older bundled server configuration, add `69c41adf883efd5e3b09ccae` to `EnabledCommonIds`, restart the server, and save the campaign character's perk selection again.

## No Flea Market

While this personal perk is selected, only trader offers remain available through the flea interface. Player listings and SPT-generated PMC offers are excluded from searches and purchases.

You cannot create or extend listings. The game's listing controls may still appear, but submitting a listing or extension returns an explanation of the restriction without taking a fee.

Existing listings can expire, settle or be removed normally. Selecting the perk does not confiscate outstanding offers or rewards. Removing it restores ordinary searches, purchases and listing access.

Trader loyalty, availability and any selected [price perks](trader-prices.md) still apply.
