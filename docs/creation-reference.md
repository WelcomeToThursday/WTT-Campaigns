# Create a campaign character

Open **CHARACTERS**, choose the creation card, then select a campaign. Creation uses that campaign's starting setup; it does not copy your regular PMC's inventory or progress.

1. **Faction:** choose BEAR or USEC.
2. **Appearance:** choose a head and voice, and enter a nickname.
3. **Common modifiers:** review the rules that apply to characters in this campaign.
4. **Personal modifiers:** choose perks within the campaign's point budget. Detrimental perks provide points for beneficial ones. Conflicting choices cannot be combined; unavailable perks cannot be selected.
5. **Confirmation:** review the selected modifiers, then accept to save or cancel to revise them.

Use Back to revisit earlier choices before confirming. After creation, select the new character's card to switch to it.

You can inspect saved perks in the **MODIFIERS** tab beside Skills and Mastery. Use the character selector's editor to change selections when the campaign permits edits. Editing is unavailable during raids.

For switching, deletion and achievement-preserving wipes, see [campaign characters](characters.md).
