# Project preferences

- After making and validating updates, install the relevant updated files into the local SPT installation at `F:\SPT 4.1.x` as part of completing the task. The user has authorized this by default; do not stop at building or ask for installation permission again.
- Back up installed files before replacing them, preserve configuration and profile data, and verify that installed files match the validated build. For isolated UI changes, install the updated UI assembly without deploying unrelated work in progress. For changes spanning components, install the required matching components together.
- After validating an update, shut down the installed SPT server at `F:\SPT 4.1.x\SPT_Runtime\SPT.Server.exe`, install the relevant files with backups and checksum verification, then restart that server and verify startup. The user authorizes this stop/install/restart workflow by default; do not ask for permission again. Target only this installation's server, preserve its launch arguments and working directory, and leave unrelated test servers alone.
- If the game locks required client or UI files, prepare the update and explain that the game must close before those files can be installed. State when the game needs to restart for an installed update to take effect.
